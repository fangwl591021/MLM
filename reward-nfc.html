NFC 寫入流程

  1. 手機安裝 NFC Tools 或同類型 NFC 寫入工具。
  2. 選擇 Write / Add a record / URL。
  3. 貼上上方短網址。
  4. 靠近 NFC Tag 寫入。
  5. 用另一支手機感應測試。

發點判定流程

  1. 會員感應 NFC。
  2. 手機開啟 LINE LIFF 領取頁。
  3. LINE 驗證會員 UID。
  4. 系統讀取 Google 日曆目前進行中的活動。
  5. 手機定位在活動地點範圍內才發放 K點。
